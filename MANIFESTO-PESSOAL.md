# Meu Manisfesto Pessoal

## Por que eu estou aqui?
Eu não estou aqui pra decorar comando. Quero entender como as coisas funcionam por dentro e usar isso para construir e proteger, nunca para invadir o que não é meu.

## O que eu prometo a mim mesmo?
1. Só ataco o que é meu ou o que tenho autorização para atacar.
2. Documento cada laboratório como se fosse prestar contas.
3. Entendo o "porque" antes de copiar o "como".
